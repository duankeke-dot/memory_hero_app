## 🎮 游戏核心机制

### 统一的评分系统
```dart
// 所有游戏使用统一的 TrainingRecord 模型
TrainingRecord.create(
  childId: child.id,
  moduleId: module_id,
  moduleName: module_name,
  trainingType: training_type,
  difficulty: level,
).copyWith(
  score: 0-100,
  maxScore: 100,
  completed: true/false,
  durationSeconds: xxx,
);
```

### 分级难度设计
- Level 1-2: 入门（6-7 岁）
- Level 3-4: 进阶（8-9 岁）
- Level 5+: 挑战（10-12 岁）

### 激励反馈
- 即时反馈：正确/错误提示
- 星星奖励：3 星（90%+）、2 星（70%+）、1 星（50%+）
- 进度追踪：连续打卡、总训练次数

## 📞 技术支持

### 常见问题

**Q: 如何修改游戏难度？**
A: 在每个游戏 screen 中调整 `_level` 相关逻辑

**Q: 如何添加新游戏？**
A: 
1. 在对应模块文件夹创建新 screen
2. 在 `routes.dart` 添加路由
3. 在 `TrainingModule.allModules` 注册

**Q: 如何修改评分标准？**
A: 调整 `_saveResult()` 方法中的 score 计算逻辑
